#### Архитектура приложения
Приложение состоит из 3-х страниц с различными функциями, навгиация по нему осуществляется с помощью меню, расположенного в верхней панели приложения.
1. 1-я страница реализует функционал по рассчету 1-й функции представленной чуть выше. Страница допускает ввод в поля только целоцисленных значений.
2. 2-я страница позволяет рассичтать значение функции в зависимости от условия, на странице также присутствует возможность выбрать f(x). Принимает также, только целочисленные значения.
3. 3-я страница содержит в себя функционал построения графика функции в зависимости от введенных значений, шага функции и диапозона значений.
